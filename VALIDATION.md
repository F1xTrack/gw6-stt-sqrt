# Проверки GW6 Voice

## Что подтверждено

- Собраны debug APK телефона и часов с одним application ID и сертификатом подписи.
- 50 JVM-тестов: математика, смешанная разметка, контекст, протокол и SVG; HTTPS mock-сервер проверяет STT multipart, заголовки, модель, контекст LLM, ответы и ошибки. Перенаправления и автоматические повторы HTTP отключены.
- Android Lint проходит для обоих приложений. Отключён только `NullSafeMutableLiveData`: detector из Lifecycle несовместим с Kotlin analysis API AGP 8.7 и падал внутри анализатора. Приложение использует StateFlow. Остальные проверки включены; остаются предупреждения о более новых зависимостях, target SDK и ресурсе capability, который Google Play services читает по имени.
- На подключённом Redmi Note 10 Pro (Android 16, API 36) прошли **5 телефонных инструментальных тестов**: реальная отрисовка LaTeX и SVG, Keystore, защита Room от повторной вставки, восстановление из сохранённого состояния незавершённого HTTP-вызова.
- Там же прошли **4 теста состояния часового приложения**: сохранение и повторное чтение состояния, защита от устаревших ответов, удаление без повторного появления при синхронизации и новый диалог с сохранением истории.
- Телефонный интерфейс запущен, формулы и SVG визуально просмотрены. Часовой интерфейс просмотрен в круглом контейнере 225 dp на Redmi; это предпросмотр размера и обрезания, а не тест Wear OS на GW6.

## Свидетельства

В `artifacts/validation/` находятся журналы финальной сборки и инструментальных тестов, PNG нативного рендерера и скриншоты. Общие отчёты: `core/build/reports/tests/test/index.html`; lint: `phone/build/reports/lint-results-debug.html` и аналогичный путь в `wear`.

Первый инструментальный прогон выявил отсутствие serialization compiler plugin в Android-модулях: 2 из 5 тестов не прошли. Плагины добавлены в оба модуля; повторный прогон прошёл. Ранее локальные HTTPS-тесты выявили несовпадение имени сертификата тестового сервера с Windows canonical hostname; исправлен адрес теста на localhost. Проверка TLS в приложении не отключалась.

Попытки запустить отдельный Android-эмулятор не дали доступного Android через ADB: сначала мешали настройки диска, затем гостевая система оставалась offline. Это не засчитывается как успешный runtime-тест. Для нативных проверок использован физический Redmi; запущенные процессы тестового эмулятора остановлены.

## Что пока UNAVAILABLE

- Физическая связка **OnePlus 10 Pro ↔ Galaxy Watch 6**: устройства не подключены к рабочей среде.
- Реальная запись с микрофона GW6, точность распознавания русской математической диктовки, качество ответов выбранной пользователем модели и её SVG.
- Полный путь с вашими облачными endpoint, ключами и моделями: конфигурация и ключи не предоставлялись. Внешние облачные API для тестов не вызывались; тестовые HTTP-сценарии локальные.
- Реальные потери Bluetooth, перезагрузка часов/телефона в ходе передачи, фоновые ограничения OxygenOS, энергопотребление и сквозная задержка.

Проверки хранения и восстановления используют контролируемые состояния в тестах; они не заменяют фактическое прерывание облачного вызова или связи на целевых устройствах.

## Приёмка на OnePlus и GW6

После установки обоих APK и настройки API проверить: обычный вопрос при заблокированном телефоне; вложенные корни, дроби и уточнение неоднозначной диктовки; продолжение диалога; SVG график и чертёж; отключение и восстановление связи; ручной повтор после неопределённого результата. Отдельно проверить погасший экран во время записи и остановку микрофона после «Стоп»/отмены.
