# GW6 Voice

Голосовой помощник для Galaxy Watch 6 и Android-телефона. Микрофон часов → STT на вашем endpoint → облачная LLM на другом endpoint → текст, LaTeX и статические SVG на часах.

Проект: `G:\_Projects\gw6-stt-sqrt`. Целевые устройства: Galaxy Watch 6 и OnePlus 10 Pro с Google Play services. Собственный сервер приложения не нужен.

## Установка

APK не хранятся в Git. Соберите их командой из раздела «Сборка и проверки»; скрипт положит `gw6-voice-phone.apk` и `gw6-voice-wear.apk` в локальный `artifacts/`. Оба APK должны быть установлены и подписаны одним сертификатом; одинаковый application ID — `dev.f1xtrack.gw6voice`. Часы должны быть сопряжены с телефоном через Galaxy Wearable.

1. Установите телефонный APK на OnePlus, откройте «Настройки».
2. Укажите **полный URL метода**, ключ и ID модели отдельно для STT и LLM. Приложение не дописывает `/v1` или другие части пути.
3. Пример STT: `https://your-provider.example/v1/audio/transcriptions`; LLM: `https://your-provider.example/v1/chat/completions`. Эти адреса — примеры, готовых сервисов и ключей в APK нет.
4. Сохраните настройки. При желании проверьте LLM или выберите аудиофайл для проверки STT. Эти кнопки отправляют запросы вашему провайдеру.
5. Установите часовой APK через беспроводную отладку Wear OS. Откройте приложение, разрешите микрофон и уведомления.
6. Проверьте связь, нажмите «Записать вопрос», произнесите вопрос, затем «Стоп → отправить».

Для установки через ADB всегда указывайте правильный serial:

```powershell
adb -s <phone-serial> install -r artifacts/gw6-voice-phone.apk
adb -s <watch-serial> install -r artifacts/gw6-voice-wear.apk
```

При включённой беспроводной отладке сначала выполните `adb pair <watch-address>:<pair-port>`, затем `adb connect <watch-address>:<debug-port>`. Порты показывает сама система часов.

## Настройка API

- Поддерживаются OpenAI-совместимые `audio/transcriptions` (multipart, ответ JSON с `text`) и `chat/completions` (ответ в `choices[0].message.content`). Native Responses API, Gemini и Anthropic не подключаются напрямую.
- Авторизация: Bearer key; при необходимости дополнительные заголовки задаются JSON-объектом строк. Дополнительный `Authorization` заменяет Bearer-заголовок.
- Параметры STT задаются JSON-объектом и добавляются полями multipart; параметры LLM добавляются в JSON запроса. Например, `{"temperature":0.3,"max_tokens":2000}`. Поддержка каждого параметра зависит от вашего сервиса.
- Служебные `model`, `file`, `messages`, `stream` нельзя переопределить дополнительными параметрами. Потоковый вывод отключён: формулы и рисунки отображаются после получения полного ответа.
- Протокол HTTPS обязателен. Проверка сертификатов включена, HTTP-перенаправления отключены. Ключи защищены Android Keystore и не отправляются на часы; резервное копирование данных приложения отключено.
- Язык распознавания по умолчанию `ru`; пустое поле не отправляет параметр языка. Запись по умолчанию AAC/M4A (16 кГц, моно, 32 кбит/с); переключатель WAV выбирает PCM16/16 кГц/моно. Изменение применяется после синхронизации настроек с часами.
- Тайм-аут по умолчанию 120 секунд на вызов. Для очень медленных API учитывайте системные ограничения Android на длительность фоновых заданий.

## Ответы, формулы и рисунки

Модель получает инструкцию сначала показать результат, затем краткие шаги. Контекст включает до 12 последних целых пар реплик в пределах заданного бюджета символов. «Новый диалог» начинает новый контекст. На телефоне можно исправить расшифровку и отправить вопрос заново.

Математические разделители: `\(...\)`, `\[...\]`, `$...$`, `$$...$$`; также fenced блоки `math`, `tex`, `latex`. Формулы выводятся JLaTeXMath нативно. `sqrt(1+sqrt(4))` в математике преобразуется с сохранением скобок; программные блоки кода сохраняются буквально. Длинные формулы разбиваются по верхнеуровневым операциям. Если формула всё равно слишком велика для читаемого вывода на часах, полный ответ доступен на телефоне.

Для SVG модель должна вернуть отдельный блок:

````markdown
```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 320 260">
  <rect width="320" height="260" fill="#101820"/>
  <circle cx="160" cy="130" r="70" fill="none" stroke="#80e7cd" stroke-width="4"/>
  <text x="130" y="138" font-size="22" fill="#ecf3f8">r = 1</text>
</svg>
```
````

Рисунок автоматически вписывается в ширину: увеличения, перемещения, JS и интерактивных элементов нет. Поддерживается ограниченный статический SVG с фигурами, путями, текстом, градиентами и маркерами; CSS, `use`, HTML, внешние ресурсы и исполняемый код запрещены. Некорректный блок заменяется сообщением, остальная часть ответа остаётся доступной. При ошибке формата выполняется максимум один дополнительный запрос исправления к LLM; это тоже вызов вашего API.

На обоих устройствах есть демо формул и SVG: оно не обращается к облаку. Приложение обеспечивает передачу и отображение; качество расшифровки, решения и геометрии рисунков определяется выбранными моделями. Исходная расшифровка доступна для проверки.

## Восстановление

Задания и результаты имеют постоянные ID. Data Layer передаёт большие данные как Asset; его данные могут синхронизироваться через инфраструктуру Google при недоступности прямой Bluetooth-связи. Телефон хранит задания в Room; часы сохраняют локальные данные атомарно. После успешного STT исходная аудиозапись удаляется с обеих сторон. Неудавшуюся запись можно повторить или удалить.

Повторная доставка одного задания не вызывает модель второй раз. Если приложение прервалось во время внешнего HTTP-вызова, результат может быть неизвестен: автоматического повторного вызова нет, доступна кнопка «Повторить». Отмена не гарантирует остановку уже выполняющегося запроса на стороне провайдера.

Android и OxygenOS могут откладывать фоновую работу; приложение показывает её состояние. При проблемах проверьте доступ приложения к интернету, разрешённые уведомления, сопряжение часов и фактические ограничения батареи для GW6 Voice. Принудительная остановка приложения в системных настройках отличается от обычного закрытия экрана.

## Сборка и проверки

Нужны JDK 17 и Android SDK Platform 36 с Build Tools. Gradle Wrapper включён. Укажите SDK в `local.properties` (`sdk.dir=G:/AndroidStudio`) или передайте путь скрипту:

```powershell
.\scripts\build.ps1 -SdkPath G:\AndroidStudio -JavaPath 'C:\Program Files\Java\jdk-17'
.\gradlew.bat :core:test
```

Инструментальные проверки устанавливайте только на выбранный тестовый Android:

```powershell
.\gradlew.bat :phone:assembleDebugAndroidTest
adb -s <test-device> install -r phone/build/outputs/apk/debug/phone-debug.apk
adb -s <test-device> install -r phone/build/outputs/apk/androidTest/debug/phone-debug-androidTest.apk
adb -s <test-device> shell am instrument -w dev.f1xtrack.gw6voice.test/androidx.test.runner.AndroidJUnitRunner
```

Модули: `core` — протокол, разбор ответов, SVG-проверка и HTTP-клиент; `render` — общая нативная отрисовка; `phone` — настройки, Room и облачный pipeline; `wear` — микрофон, диалоги и вывод. Первое разрешение некоторых Android-зависимостей в данной среде потребовало зеркала Google Maven; оно ограничено группами Android/Google. Состояние фактических проверок — в `VALIDATION.md`.
